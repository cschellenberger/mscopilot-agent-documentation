## 📖 BPMN 2.0 Coaching Guide

The BPMN 2.0 Coaching Guide is designed for IT Business Analysis Professionals who are learning Business Process Model and Notation (BPMN) 2.0 for the first time. It covers:

- ✅ Core BPMN 2.0 elements and notation
- ✅ OMG compliance requirements
- ✅ Best practices for professional diagrams
- ✅ Common mistakes and how to avoid them
- ✅ Hands-on practical exercises
- ✅ Certification pathways and learning resources

### Quick Start

1. Read the [Introduction to BPMN 2.0](./BPMN-2.0-Coaching-Guide.md#introduction-to-bpmn-20)
2. Study the [Core Elements](./BPMN-2.0-Coaching-Guide.md#core-bpmn-20-elements)
3. Review [Compliance Requirements](./BPMN-2.0-Coaching-Guide.md#compliance-requirements)
4. Complete the [Practical Exercises](./BPMN-2.0-Coaching-Guide.md#practical-exercises)

For the BPMN 2.0 Guide:
